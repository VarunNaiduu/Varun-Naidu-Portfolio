## Run Locally

This is a static website. No dependency installation is required.

1. Clone your repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Open the repository folder:

   ```bash
   cd YOUR_REPOSITORY
   ```

3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open `http://localhost:8000` in your browser.

You can also open `index.html` directly in a browser for a quick local preview.

## Deploy with GitHub Pages

1. Upload the website files to the root of a GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Click **Save** and wait for GitHub Pages to publish the site.

For a repository named `varun-naidu-portfolio`, the URL will usually follow this format:

`https://YOUR_USERNAME.github.io/varun-naidu-portfolio/`

Replace `YOUR_USERNAME` with your GitHub username.

## Required Files

Recommended repository structure:

```text
varun-naidu-portfolio/
├── index.html
├── Varun_Naidu_Resume.pdf
└── README.md
```

**Important before deployment:**
- Rename the uploaded portfolio file to `index.html`. GitHub Pages expects an index file at the published root.
- The HTML links to the resume as `Varun_Naidu_Resume.pdf`. Rename your resume PDF to exactly that filename and place it beside `index.html`, or update the resume link in the HTML to match the PDF's actual filename.
- The contact form's `formEndpoint` is currently empty. Configure a form service endpoint if you want form submissions to be sent directly; otherwise, test the current fallback behavior before publishing.
